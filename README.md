# Bloglist CI/CD

This repository contains my work from the Full Stack Open course, focusing on building a full-stack Bloglist application and setting up a CI/CD pipeline.

The project includes a React frontend, Node.js and Express backend, automated testing, Docker, and continuous integration and deployment.

## Technologies

* React
* Node.js
* Express
* MongoDB
* JavaScript
* Docker
* GitHub Actions
* Playwright
* Fly.io
